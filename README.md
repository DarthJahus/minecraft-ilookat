# I Look At

Broadcast what you are looking at to all players with `/ilookat`.

## Usage

```
/ilookat
```

Example:

    Jahus_ is looking at Oak Planks
    Jahus_ is looking at Zombie
    Jahus_ is looking at Lava

## Behavior

- Reach: **6 blocks**
- Cooldown: **15 seconds**
- See-through: **water** and **glass** (1 bloc)
- Stops on: **lava**, solid blocks, entities
- Item frames: shows the item inside

Server-only: clients do not need the mod installed.
