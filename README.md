# I Look At

Broadcast what you are looking at to all players with `/ilookat`.

[![Modrinth](https://img.shields.io/modrinth/dt/jahus-ilookat?logo=modrinth&label=Modrinth)](https://modrinth.com/mod/jahus-ilookat)
[![CurseForge](https://img.shields.io/curseforge/dt/1720166?logo=curseforge&label=CurseForge)](https://www.curseforge.com/projects/1720166)

## Usage

```
/ilookat
```

Example:

    Jahus_ is looking at Oak Planks
    Jahus_ is looking at Zombie
    Jahus_ is looking at Lava

## Behavior

- Reach: **6 blocks**
- Cooldown: **15 seconds**
- See-through: **water** and **glass** (1 bloc)
- Stops on: **lava**, solid blocks, entities
- Item frames: shows the item inside

Server-only: clients do not need the mod installed.
